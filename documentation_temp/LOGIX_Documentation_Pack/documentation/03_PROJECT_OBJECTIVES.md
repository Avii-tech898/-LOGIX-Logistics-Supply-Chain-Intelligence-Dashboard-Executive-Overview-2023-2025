# Project Objectives

## Primary Objectives
1. Build a realistic logistics dataset for India.
2. Maintain referential integrity across operational tables.
3. Validate master and transactional data.
4. Store the data in MySQL.
5. Build reusable SQL views and analytical queries.
6. Perform Python-based analytics.
7. Build Excel reporting.
8. Build Power BI business intelligence reporting.
9. Provide a Streamlit analytics interface.
10. Add machine-learning use cases for predictive logistics decisions.

## Quality Objectives
- Valid primary and foreign keys
- Valid date relationships
- Controlled status transitions
- No invalid negative quantities or monetary values
- Reproducible synthetic generation using a fixed seed
- Traceable analytical calculations
